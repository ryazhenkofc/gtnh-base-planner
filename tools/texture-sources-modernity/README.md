# Modernity texture overrides

Drop PNGs here named after an atlas tile (the same names as in `tools/texture-sources/`, e.g.
`MACHINE_CASING_SOLID_STEEL.png`) and run `npm run atlas`. Tiles with a file here are replaced in
`public/textures/atlas-modernity.png`; every other tile keeps the classic look. The "Modernity textures"
toggle in Settings switches the DETAILED view to that atlas.

Only add files whose licence allows redistribution, and list them in `ATTRIBUTION.md`.
